Featured Cybersecurity Project

Cowrie Honeypot with Wazuh SIEM Monitoring

A controlled blue-team lab designed to study attacker behavior, simulate SSH-based intrusions, and analyze security telemetry through honeypot logs and SIEM monitoring.

Cowrie Wazuh Kali Linux Ubuntu Threat Detection

Project Overview

I deployed a Cowrie SSH honeypot inside a virtualized Linux lab and used Kali Linux to simulate attacker interactions. The project explored brute-force attempts, credential harvesting, post-login attacker behavior, bot-style automated commands, and malware download attempts.

Objectives

Capture realistic SSH attack behavior
Analyze attacker commands and intent
Forward and review logs in Wazuh
Document blue-team observations

Lab Architecture

Attack Scenarios Demonstrated

SSH brute-force attempts
Credential harvesting
Post-exploitation shell commands
Automated bot-style actions
Malware download attempt simulation

Evidence from the Lab

Key Security Learnings

  • How attackers test weak SSH credentials
  • Why command telemetry matters after access is gained
  • How honeypot logs can support threat detection
  • How SIEM tooling improves security visibility
