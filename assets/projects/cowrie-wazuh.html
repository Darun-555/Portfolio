Cowrie Honeypot with Wazuh SIEM Monitoring

A hands-on cybersecurity lab focused on SSH honeypot deployment, attacker behavior simulation, and log-based detection workflows.

What I Built

I deployed a Cowrie honeypot in a controlled virtual lab, simulated attacker behaviors from Kali Linux, and incorporated SIEM-style monitoring using Wazuh.

Attack Scenarios

SSH brute-force attempts, credential harvesting, post-exploitation commands, automated bot activity, and malware download attempt simulation.

Tools Used

Cowrie, Kali Linux, Ubuntu, Wazuh, Bash, Linux logs.
